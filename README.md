# swap_web
## Project Introduction
This is a second-hand trading platform website for campus services. Technical exchanges are welcome. Official website: www.pcquick.cn
## Deployment Tutorial
### Deploy locally
First, install dependencies on the local computer
```
pip install -r requirements.txt
```
If you want to deploy locally, after pulling the source code of this project, install the Python environment, MySQL database, Django framework on your computer, and then open the command prompt in the project directory and run the startup command
```
python manage.py runserver 0.0.0.0:8000
```
Then enter localhost in the local browser to view
```
localhoat:8080
```
